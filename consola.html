Guía Rápida de Pseudocódigo

1. Estructura General

El cuerpo del programa principal se encierra entre la palabra comienza y finaliza con termina.

2. Declaración de Datos (Orden Correcto)

Si tu programa usa datos o tipos, se recomienda usar este orden para las definiciones arriba del comienza:

  1. constantes (Ej: PI = 3.14)
  2. tipos (Ej: Arreglos)
  3. variables (Ej: nombre : cadena)

3. Salida por Consola

Usa escribir("Hola") si quieres imprimir sin saltar de línea. Si quieres que el próximo texto vaya en una línea nueva, usa escribirln("Hola").

4. Estructuras de Control

  • Condicional: si [condicion] entonces ... sino ... finsi (o fin si).
  • Bucle Mientras: mientras [condicion] hacer ... finmientras (o fin mientras).
  • Bucle Para: para i <- 1 hasta 10 hacer ... finpara (o fin para).
  • Bucle Repetir: repetir ... hasta [condicion].
